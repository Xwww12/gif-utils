# GIF Utils

一个简洁的 Windows 桌面工具：制作 GIF、烧录字幕、下载 X 视频、查看图片信息。

## 可以做什么

| 功能 | 用途 |
| --- | --- |
| MP4 转 GIF | 选择视频片段，调整清晰度和文件大小，生成 GIF |
| 字幕烧录 | 将字幕永久嵌入视频，支持 CPU 和 GPU 编码 |
| X 视频下载 | 解析公开帖子链接，选择视频与画质后保存 |
| 图片信息 | 查看图片尺寸、拍摄参数、GPS，并手动查询附近地址 |

## 开始使用

使用环境：Windows 11 64 位。源码构建需要 .NET 10 SDK；通过发布脚本生成的程序自带运行环境，无需另外安装 .NET。

**本仓库保存源码，不包含可直接运行的 EXE。** 从 GitHub 下载源码后，请按文末的“从源码构建”生成程序。如果已有打包版，解压后打开 `GIFUtils.exe` 即可。

视频相关功能需要 FFmpeg，图片信息查看不需要：

1. 准备 `ffmpeg.exe` 和 `ffprobe.exe`，将它们放在同一个文件夹中。FFmpeg 需要支持 GIF 调色板和 `subtitles/libass` 字幕滤镜。
2. 打开程序。如果没有自动找到 FFmpeg，点击“选择 FFmpeg”，选中 `ffmpeg.exe`。
3. 显示“FFmpeg 已就绪”后，即可使用视频功能。

也可以把这两个文件放在程序旁的 `tools` 文件夹里，方便换电脑使用：

```text
GIF Utils/
├─ GIFUtils.exe
├─ licenses/
└─ tools/
   ├─ ffmpeg.exe
   └─ ffprobe.exe
```

FFmpeg 不随本项目提供。转移打包版时请保留第三方许可文件；不要依赖原电脑上的快捷方式或磁盘路径。

## MP4 转 GIF

1. 打开“MP4 转 GIF”，选择视频和保存位置。
2. 选择压缩模式。不确定怎么选时，先用“均衡”；想缩小文件可选“小体积”或“极小”。
3. 如果只需要一段视频，展开“截取时间（可选）”选择范围。
4. 点击顶部“开始转换”，等待进度完成。

### 怎么控制文件大小

- **目标上限（MB）**：希望 GIF 尽量不超过的大小，在“指定目标大小”模式下生效。程序会尝试降低画质，但不保证一定达标。
- **最大宽度**：GIF 的像素宽度上限；越小通常文件越小。
- **帧率 FPS**：每秒显示多少张画面；越高越流畅，也通常越大。
- **颜色数量**：可使用的颜色数；越少通常越小，但渐变和细节可能变差。
- **颜色抖动**：用相邻像素模拟更多颜色，让渐变更自然；不确定时保留默认值。

文件仍然太大时，优先缩短片段，再降低宽度、帧率和颜色数。界面中的小问号也有参数说明。

### 怎么选择片段

- 拖动左右两侧的小手柄，设置起点和终点；靠近播放指针时会自动吸附。
- 点击或拖动缩略图、下方播放条，只改变播放位置，不改变选区。
- 使用下方图标播放/暂停、从选区起点重播、循环选区，或恢复整段。
- 也可以直接输入起止时间：支持秒数、`mm:ss` 和 `hh:mm:ss`，可带小数。例如 `01:30` 表示 90 秒。

预览播放的是**选中的原视频片段，无声**，不是最终 GIF 效果。时间轴获得焦点后，左右键移动播放位置，`Shift + 左右键` 调整起点，`Ctrl + 左右键` 调整终点，每次移动 0.05 秒。

## 字幕烧录

1. 打开“字幕烧录”，选择视频和字幕文件，支持 SRT、ASS、SSA、VTT。
2. 选择保存位置，输出为 MP4 或 MKV。
3. 编码方式优先选“自动（推荐）”；也可手动选择 CPU、NVIDIA、Intel 或 AMD。
4. 点击“开始烧录”，在顶部查看进度；需要中止时点击“取消”。

烧录后的字幕成为画面的一部分，不能像外挂字幕一样关闭。处理需要重新编码，可能损失少量画质；质量数值越低，通常画质越高、文件越大。GPU 是否可用取决于显卡、驱动和 FFmpeg，自动模式在硬件编码不可用时会使用 CPU。

## X 视频下载

1. 打开“X 下载”，粘贴 `x.com`、`twitter.com` 或 `t.co` 的帖子链接。
2. 点击“解析链接”，勾选需要下载的媒体并选择画质。
3. 选择保存目录，可按需填写文件名前缀。
4. 点击“开始下载”。完成后可点击“打开文件夹”查看文件。

首次使用会联网下载并校验 yt-dlp 解析组件，需要能访问 GitHub。X 上的动图会保存为 MP4；同名文件会自动加后缀，避免覆盖。

仅支持无需登录即可访问的公开帖子的原生视频/动图，不读取浏览器 Cookie，不处理私密、付费、受限内容、直播或 DRM。请只下载有权保存的内容；X 接口变化可能导致解析失败。

## 图片信息

1. 打开“图片信息”，选择或拖入一张图片。
2. 查看尺寸、拍摄时间、设备、镜头、光圈、快门、ISO、焦距等信息，以及图片内记录的 GPS。
3. 如果有有效经纬度，可点击“解析地址”，确认后查询城市/区县和附近街道、社区或地标。

支持 JPG、PNG、WebP、TIFF、BMP、GIF、HEIC/HEIF、AVIF 等格式；能显示哪些信息取决于原图记录。没有记录的字段显示“未记录”，不会根据文件日期或图片内容猜测。

图片信息在本地读取，不修改原图。**只有点击“解析地址”并确认后，才会将经纬度发送给 Photon 地图服务**，不上传图片。地址是附近位置匹配，不保证精确到建筑或门牌；敏感照片请勿联网解析。

地图数据 © [OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)，遵循 ODbL；地址查询使用 [Photon](https://github.com/komoot/photon)。

## 从源码构建

在 Windows 上安装 .NET 10 SDK，在项目根目录打开 PowerShell：

```powershell
# 编译与测试
dotnet build .\FFmpegUtils.slnx -c Release
dotnet run --project .\tests\FFmpegUtils.SmokeTests -c Release

# 生成 Windows 64 位独立运行版
.\publish.ps1
```

生成的程序位于 `artifacts\publish\win-x64\GIFUtils.exe`。分发时复制整个 `win-x64` 文件夹，再按“开始使用”准备 FFmpeg。

项目使用 C#、WPF 和 .NET 10。为兼容旧设置，源码项目名仍为 `FFmpegUtils`，设置和下载组件缓存仍保存在 `%LOCALAPPDATA%\FFmpegUtils`。构建产物、个人设置和本机快捷方式不提交到仓库；第三方许可见 [licenses](licenses)。
